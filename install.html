Get LifeTrack from its official download page. Download the Android APK or follow the steps to add LifeTrack to iPhone, Windows, or Mac. Sign in with the same Google account to sync supported tracker data between devices.

Download iOS source project Mac/Xcode setup instructions

Mac/Xcode setup for TestFlight

  1. On a Mac, install Xcode 15 or newer from the Mac App Store, then open it once and complete its setup.
  2. Install XcodeGen using Terminal: brew install xcodegen.
  3. Download and extract the iOS source project. In Terminal, go into the extracted folder containing project.yml and run xcodegen generate.
  4. Open the generated LifeTrack.xcodeproj in Xcode. Select your Apple Developer team under Signing & Capabilities and register a bundle identifier for that team.
  5. Choose Product → Archive, then upload the archive to App Store Connect using Organizer. Add the processed build to a TestFlight group.

The Google sign-in handoff for iPhone also needs the updated LifeTrack Worker deployed. The signed iPhone app cannot be built or installed from this Windows computer. Public App Store release needs Apple's review.
